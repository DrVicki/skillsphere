# Python Forge source audit

Source: https://pyforgecourse.org/
Source bundle: https://pyforgecourse.org/assets/index-jSnxQG5e.js
Retrieved: 2026-10-21

The source course provides 10 modules, 30 guided lessons, and 12 portfolio projects. Each lesson record contains objectives, full explanations, worked example code, starter code, expected output, hints, an activity brief with steps and success criteria, a reflection prompt, and a knowledge check. Each project record contains a brief, scenario, requirements, starter code, success criteria, rubric, stretch goals, and reflection questions.

The source coding environment is a browser-based Python lab. It dynamically loads Pyodide 0.27.7 from `https://cdn.jsdelivr.net/pyodide/v0.27.7/full/pyodide.mjs`, runs Python locally in the browser, preserves learner code in browser storage, offers starter prompts and lesson-specific activities, and supports `.py` download. Source lesson URLs follow `https://pyforgecourse.org/lesson/<lesson-id>` and project URLs follow `https://pyforgecourse.org/projects/<number>`.

The source `https://pyforgecourse.org/lesson/m01-l01` confirms the lesson presentation sequence: objectives, full explanation, worked code/output, hands-on activity, embedded coding lab, static hints, definition of done, reflection, and knowledge check.
